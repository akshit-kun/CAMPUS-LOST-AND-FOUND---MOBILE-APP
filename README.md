# CAMPUS-LOST-AND-FOUND---MOBILE-APP
A Campus Lost and Found mobile application built using Android Studio, Kotlin, Firebase Authentication, Cloud Firestore, and Firebase Functions. The app allows students to report lost items, post found items, search listings, and connect with item owners.

# Campus Lost and Found App

## Overview

Campus Lost and Found App is an Android application developed to help students and staff report, search, and recover lost items within a campus environment.

The application uses Firebase services for authentication, cloud storage, and database management, providing a secure and scalable platform for item tracking.

---

## Features

- User Authentication
- Report Lost Items
- Report Found Items
- Search Listings
- Item Details View
- Firebase Cloud Firestore Integration
- Firebase Authentication
- Firebase Functions Support
- Real-time Data Updates

## Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/campus-lost-and-found-app.git
```

### Open Project

1. Open Android Studio
2. Select Open Project
3. Choose the cloned repository

### Firebase Setup

1. Create Firebase Project
2. Download google-services.json
3. Place it inside:

```
app/google-services.json
```

### Build

```bash
./gradlew build
```
